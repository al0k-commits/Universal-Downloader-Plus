# Universal Downloader+ 🚀

A modern, fast, and feature-rich video and playlist downloader built with Python. Inspired by premium tools like 4K Video Downloader+, this application features an embedded ad-blocking web browser, seamless platform integration, and advanced format selection.

## ✨ Features
* **Built-in Ad-Blocker:** Browse YouTube, Twitch, and other streaming sites without annoying ads or pop-ups.
* **Smart Format Selection:** Choose between MP4, MKV, AV01, H264, and MP3 with precise frame rate and resolution controls.
* **Modern Dual UI:** A beautiful, responsive dark/light interface powered by PyQt6 (with a CustomTkinter fallback).
* **Universal Compatibility:** Powered by `yt-dlp` to support thousands of streaming platforms.
* **Concurrent Downloads:** Background threading ensures the UI never freezes.

## 🛠️ Prerequisites
Before running the application from source, ensure you have the following installed on your system:
* Python 3.10+
* `ffmpeg` and `ffprobe` (Must be added to your system PATH or placed in the project root).
